# Personal Resume Website

A personal portfolio and resume website developed to showcase my education, technical skills, and software development projects.

## Live Demo
https://jdixon22.domains.ggc.edu/project0/index.html

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Responsive web design
- Professional resume layout
- Project and skills showcase
- Clean user interface
- Deployed live using cPanel hosting

## About the Project
This project was created as part of my coursework while pursuing a Bachelor’s degree in Computer Science with a concentration in Software Development at Georgia Gwinnett College. The website serves as an online resume and portfolio to highlight my technical background and development experience.
